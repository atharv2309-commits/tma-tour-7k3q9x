Counter-drone detection

Intruder drone detection, inside FlytBase

FlytBase integrates with Senhive detect-and-avoid sensors. When a sensor sees an unauthorised drone, the drone and its remote controller appear on the same map as your own fleet. An operator can send a response drone to the remote controller's position from that screen.

  • One screen. Detections show on the FlytBase map and in the Flinks panel. No second system and no copying of coordinates.
  • Go to RC. The Go To Location flow opens with the remote controller's coordinates filled in. The operator checks the altitudes and dispatches.
  • Docks. Works with DJI Dock 1, 2 and 3, and with non-DJI docks. It runs on FlytBase Cloud.
  • Setup. The FlytBase Solutions Engineering team enables it. It needs the Senhive virtual host, user name and password, and the serial number of each sensor.
  • Accuracy. Positions are shown as the sensor reports them. They depend on how the sensors are deployed.
